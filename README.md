# Streamlining IT Procurement – Standard Laptop Order Automation

## Project Overview

This project automates the standard laptop procurement process using
ServiceNow Flow Designer.

## Objective

To reduce manual effort, processing delays, and errors in standard
laptop ordering.

## Technology Used

- ServiceNow
- Flow Designer
- Update Sets

## Automation Flow

1. Standard laptop order is submitted.
2. Flow Designer processes the request.
3. Required approval/action is triggered.
4. The laptop order is processed automatically.

## Update Set

The ServiceNow Flow Designer configuration is exported as an XML
Update Set and stored in this repository.
